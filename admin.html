使用说明 / 安全提示

1. PAT 只存在你浏览器 localStorage，不会发到其他地方；不要把本页公开分享。
2. 建议 fine-grained token：只授权本仓库 Contents 读写，设较短有效期。
3. 添加 / 编辑 / 删除都会直接 commit 到 GitHub，Pages 刷新后生效。
4. 应用内容须自有或已授权，禁止上传盗版/侵权应用。
